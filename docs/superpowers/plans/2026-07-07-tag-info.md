# Full Tag Info Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let `ccid` read everything readable off a Type 2 Tag — UID, full raw memory, parsed Capability Container fields, and (best-effort) NXP chip identification — as independently callable methods on `CcidCard`, and show them in a dedicated details screen in the example app.

**Architecture:** Two new pure-data classes (`CapabilityContainer`, `ChipVersion`) in a new `lib/ccid_tag_info.dart`, four new I/O methods on `CcidCard` built on the existing `transceive()` channel (reusing the same chunked-page-read pattern `readNdef()` already established), and a new example-app screen that calls all five read methods (including the existing `readNdef()`) independently.

**Tech Stack:** Dart, `package:convert` (already a dependency), `flutter_test`.

## Global Constraints

- Same Type 2 Tag scope as the NDEF feature: NTAG21x, Mifare Ultralight family; Type 4 tags out of scope.
- `readChipVersion()` must never throw — any failure (unsupported escape command, bad status word, wrong response length) returns `null`.
- `readMemoryDump()` and `readNdef()`'s page-reading both stop at page `0xFF` (255) — same ceiling already established for `readNdef()`.
- No new dependencies.
- `readNdef()`'s external behavior (signature, thrown exceptions) is unchanged — only its internal CC-reading is refactored to call the new `readCapabilityContainer()`.
- Automated unit tests are for the pure parsing classes (`CapabilityContainer.parse`, `ChipVersion.parse`) only; the five I/O methods are verified manually against real hardware (an ACR1122U over USB OTG on Android).
- `readChipVersion()`'s escape command (`FF0000000160`) is a best-effort guess at the ACS/PN532-family "direct transmit" convention — it is expected to need adjustment after the first manual hardware test; that adjustment is out of scope for these tasks and will be a follow-up once real hardware results are in.

```dart
import 'dart:typed_data';

/// The parsed Capability Container (CC) of an NFC Forum Type 2 Tag.
///
/// The CC is 4 bytes, normally found at page 3 of the tag's memory.
class CapabilityContainer {
  /// The NDEF magic number byte. `0xE1` indicates the tag is NDEF-formatted.
  final int magicByte;

  /// The CC version byte (high nibble = major, low nibble = minor).
  final int version;

  /// The raw size byte. Data area size in bytes is [dataAreaSize].
  final int size;

  /// The raw read/write access byte (high nibble = read, low nibble = write).
  final int accessByte;

  CapabilityContainer({
    required this.magicByte,
    required this.version,
    required this.size,
    required this.accessByte,
  });

  /// Whether [magicByte] indicates this tag is NDEF-formatted.
  bool get isNdefFormatted => magicByte == 0xE1;

  /// The NDEF data area size in bytes, derived from [size].
  int get dataAreaSize => size * 8;

  /// The major version number, from the high nibble of [version].
  int get majorVersion => (version >> 4) & 0x0F;

  /// The minor version number, from the low nibble of [version].
  int get minorVersion => version & 0x0F;

  /// The read access condition, from the high nibble of [accessByte].
  int get readAccess => (accessByte >> 4) & 0x0F;

  /// The write access condition, from the low nibble of [accessByte].
  int get writeAccess => accessByte & 0x0F;

  /// Parses a 4-byte Capability Container.
  static CapabilityContainer parse(Uint8List bytes) {
    return CapabilityContainer(
      magicByte: bytes[0],
      version: bytes[1],
      size: bytes[2],
      accessByte: bytes[3],
    );
  }

  @override
  String toString() =>
      'CapabilityContainer(magicByte: 0x${magicByte.toRadixString(16)}, '
      'version: $majorVersion.$minorVersion, dataAreaSize: $dataAreaSize, '
      'readAccess: 0x${readAccess.toRadixString(16)}, '
      'writeAccess: 0x${writeAccess.toRadixString(16)})';
}

/// The parsed response to an NXP `GET_VERSION` (0x60) command, identifying
/// the chip model of an NTAG21x / Mifare Ultralight family tag.
///
/// This is a manufacturer-specific command, not part of the standard NFC
/// Forum Type 2 Tag operation set — see `CcidCard.readChipVersion`.
class ChipVersion {
  final int headerByte;
  final int vendorId;
  final int productType;
  final int productSubtype;
  final int majorVersion;
  final int minorVersion;
  final int storageSize;
  final int protocolType;

  ChipVersion({
    required this.headerByte,
    required this.vendorId,
    required this.productType,
    required this.productSubtype,
    required this.majorVersion,
    required this.minorVersion,
    required this.storageSize,
    required this.protocolType,
  });

  /// Parses an 8-byte GET_VERSION response.
  static ChipVersion parse(Uint8List bytes) {
    return ChipVersion(
      headerByte: bytes[0],
      vendorId: bytes[1],
      productType: bytes[2],
      productSubtype: bytes[3],
      majorVersion: bytes[4],
      minorVersion: bytes[5],
      storageSize: bytes[6],
      protocolType: bytes[7],
    );
  }

  @override
  String toString() =>
      'ChipVersion(vendorId: 0x${vendorId.toRadixString(16)}, '
      'productType: 0x${productType.toRadixString(16)}, '
      'productSubtype: 0x${productSubtype.toRadixString(16)}, '
      'version: $majorVersion.$minorVersion, '
      'storageSize: 0x${storageSize.toRadixString(16)}, '
      'protocolType: 0x${protocolType.toRadixString(16)})';
}
```

```dart
  final String reader;

  CcidCard(this.reader);

  /// Send APDU command [cpadu]
  ///
  /// Returns the response APDU
  Future<String?> transceive(String capdu) {
    return CcidPlatform.instance.transceive(reader, capdu);

  /// Disconnect from the card
  Future<void> disconnect() {
    return CcidPlatform.instance.disconnect(reader);

  /// Reads the NDEF message from an NFC Forum Type 2 Tag (e.g. NTAG213/215/216,
  /// Mifare Ultralight) connected through a contactless PC/SC reader.
  ///
  /// Throws an [Exception] if the tag has no NDEF capability container or
  /// no NDEF message is found on it.
  Future<List<NdefRecord>> readNdef() async {
    final cc = await _transceiveChecked('FFB0000304');
    if (cc.isEmpty || cc[0] != 0xE1) {
      throw Exception(
          'Tag does not contain NDEF data (no capability container found)');
    }
    final dataAreaSize = cc[2] * 8;

    final buffer = BytesBuilder();
    var page = 4;
    while (buffer.length < dataAreaSize && page <= 0xFF) {
      final pageHex = page.toRadixString(16).padLeft(2, '0');
      String? chunkHex;
      try {
        chunkHex = await transceive('FFB00000${pageHex}10');
      } catch (_) {
        break;
      }
      final chunk = _stripAndCheckSw(chunkHex);
      if (chunk == null) break;
      buffer.add(chunk);
      page += 4;
    }

    final message = parseTlvForNdefMessage(buffer.toBytes());
    if (message == null) {
      throw Exception('No NDEF message found on tag');
    }
    return parseNdefRecords(message);
  }

  Future<Uint8List> _transceiveChecked(String capdu) async {
    final data = _stripAndCheckSw(await transceive(capdu));
    if (data == null) {
      throw Exception('Failed to read tag (bad response to $capdu)');
    }
    return data;
  }

  Uint8List? _stripAndCheckSw(String? responseHex) {
    if (responseHex == null || responseHex.length < 4) return null;
    final sw = responseHex.substring(responseHex.length - 4);
    if (sw.toUpperCase() != '9000') return null;
    final dataHex = responseHex.substring(0, responseHex.length - 4);
    return Uint8List.fromList(hex.decode(dataHex));
  }
}
```

```dart
import 'dart:typed_data';

import 'package:convert/convert.dart';

import 'ccid_ndef.dart';
import 'ccid_platform_interface.dart';
import 'ccid_tag_info.dart';

export 'ccid_ndef.dart' show NdefRecord;
export 'ccid_tag_info.dart' show CapabilityContainer, ChipVersion;

class Ccid {
  /// List available readers
  ///
  /// Returns a list of reader names
  Future<List<String>> listReaders() {
    return CcidPlatform.instance.listReaders();
  }

  /// Connect to a reader by its name [reader]
  ///
  /// Returns a [CcidCard] object
  Future<CcidCard> connect(String reader) {
    return CcidPlatform.instance.connect(reader);
  }
}

class CcidCard {
  final String reader;

  CcidCard(this.reader);

  /// Send APDU command [cpadu]
  ///
  /// Returns the response APDU
  Future<String?> transceive(String capdu) {
    return CcidPlatform.instance.transceive(reader, capdu);
  }

  /// Disconnect from the card
  Future<void> disconnect() {
    return CcidPlatform.instance.disconnect(reader);
  }

  /// Reads the NDEF message from an NFC Forum Type 2 Tag (e.g. NTAG213/215/216,
  /// Mifare Ultralight) connected through a contactless PC/SC reader.
  ///
  /// Throws an [Exception] if the tag has no NDEF capability container or
  /// no NDEF message is found on it.
  Future<List<NdefRecord>> readNdef() async {
    final cc = await readCapabilityContainer();
    if (!cc.isNdefFormatted) {
      throw Exception(
          'Tag does not contain NDEF data (no capability container found)');
    }
    final data = await _readPagesFrom(4, maxBytes: cc.dataAreaSize);
    final message = parseTlvForNdefMessage(data);
    if (message == null) {
      throw Exception('No NDEF message found on tag');
    }
    return parseNdefRecords(message);
  }

  /// Reads the tag's UID via the standard PC/SC "Get Data" pseudo-APDU.
  Future<Uint8List> readUid() {
    return _transceiveChecked('FFCA000000');
  }

  /// Reads and parses the tag's Capability Container (CC), normally found
  /// at page 3 of an NFC Forum Type 2 Tag's memory.
  Future<CapabilityContainer> readCapabilityContainer() async {
    final bytes = await _transceiveChecked('FFB0000304');
    return CapabilityContainer.parse(bytes);
  }

  /// Reads the tag's full raw memory, starting at page 0, until a page
  /// read fails or the page number would no longer fit in one byte.
  ///
  /// This includes the UID pages, lock bytes, Capability Container, NDEF
  /// data area, and any further manufacturer-specific pages (e.g.
  /// configuration/counter pages) the tag exposes.
  Future<Uint8List> readMemoryDump() {
    return _readPagesFrom(0);
  }

  /// Attempts to read the tag's chip identification via the NXP
  /// `GET_VERSION` (0x60) command.
  ///
  /// This is not part of the standard NFC Forum Type 2 Tag operation set —
  /// it requires the reader to support a "direct transmit" style escape
  /// command. Returns `null` if the reader doesn't support this, the
  /// command fails, or the response isn't the expected 8 bytes, rather
  /// than throwing.
  Future<ChipVersion?> readChipVersion() async {
    String? responseHex;
    try {
      responseHex = await transceive('FF0000000160');
    } catch (_) {
      return null;
    }
    final data = _stripAndCheckSw(responseHex);
    if (data == null || data.length != 8) {
      return null;
    }
    return ChipVersion.parse(data);
  }

  Future<Uint8List> _readPagesFrom(int startPage, {int? maxBytes}) async {
    final buffer = BytesBuilder();
    var page = startPage;
    while ((maxBytes == null || buffer.length < maxBytes) && page <= 0xFF) {
      final pageHex = page.toRadixString(16).padLeft(2, '0');
      String? chunkHex;
      try {
        chunkHex = await transceive('FFB00000${pageHex}10');
      } catch (_) {
        break;
      }
      final chunk = _stripAndCheckSw(chunkHex);
      if (chunk == null) break;
      buffer.add(chunk);
      page += 4;
    }
    return buffer.toBytes();
  }

  Future<Uint8List> _transceiveChecked(String capdu) async {
    final data = _stripAndCheckSw(await transceive(capdu));
    if (data == null) {
      throw Exception('Failed to read tag (bad response to $capdu)');
    }
    return data;
  }

  Uint8List? _stripAndCheckSw(String? responseHex) {
    if (responseHex == null || responseHex.length < 4) return null;
    final sw = responseHex.substring(responseHex.length - 4);
    if (sw.toUpperCase() != '9000') return null;
    final dataHex = responseHex.substring(0, responseHex.length - 4);
    return Uint8List.fromList(hex.decode(dataHex));
  }
}
```

```dart
import 'package:ccid/ccid.dart';
import 'package:flutter/material.dart';

class TagDetailsPage extends StatefulWidget {
  final CcidCard card;

  const TagDetailsPage({super.key, required this.card});

  @override
  State<TagDetailsPage> createState() => _TagDetailsPageState();
}

class _TagDetailsPageState extends State<TagDetailsPage> {
  String? _uidResult;
  String? _capabilityContainerResult;
  String? _ndefResult;
  String? _memoryDumpResult;
  String? _chipVersionResult;

  @override
  void initState() {
    super.initState();
    _loadUid();
    _loadCapabilityContainer();
    _loadNdef();
    _loadMemoryDump();
    _loadChipVersion();
  }

  Future<void> _loadUid() async {
    try {
      final uid = await widget.card.readUid();
      setState(() => _uidResult = _hex(uid));
    } catch (e) {
      setState(() => _uidResult = 'Failed: $e');
    }
  }

  Future<void> _loadCapabilityContainer() async {
    try {
      final cc = await widget.card.readCapabilityContainer();
      setState(() => _capabilityContainerResult = cc.toString());
    } catch (e) {
      setState(() => _capabilityContainerResult = 'Failed: $e');
    }
  }

  Future<void> _loadNdef() async {
    try {
      final records = await widget.card.readNdef();
      setState(() {
        _ndefResult =
            records.isEmpty ? '(empty message)' : records.join('\n');
      });
    } catch (e) {
      setState(() => _ndefResult = 'Failed: $e');
    }
  }

  Future<void> _loadMemoryDump() async {
    try {
      final dump = await widget.card.readMemoryDump();
      setState(() => _memoryDumpResult = _formatPages(dump));
    } catch (e) {
      setState(() => _memoryDumpResult = 'Failed: $e');
    }
  }

  Future<void> _loadChipVersion() async {
    try {
      final version = await widget.card.readChipVersion();
      setState(() {
        _chipVersionResult = version == null
            ? 'Unavailable (reader/tag does not support GET_VERSION)'
            : version.toString();
      });
    } catch (e) {
      setState(() => _chipVersionResult = 'Failed: $e');
    }
  }

  String _hex(List<int> bytes) =>
      bytes.map((b) => b.toRadixString(16).padLeft(2, '0')).join();

  String _formatPages(List<int> bytes) {
    final lines = <String>[];
    for (var i = 0; i < bytes.length; i += 4) {
      final page = i ~/ 4;
      final end = i + 4 > bytes.length ? bytes.length : i + 4;
      final chunk = bytes.sublist(i, end);
      lines.add('Page $page: ${_hex(chunk)}');
    }
    return lines.isEmpty ? '(empty)' : lines.join('\n');
  }

  Widget _section(String title, String? content) {
    return Padding(
      padding: const EdgeInsets.only(bottom: 16.0),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Text(title, style: const TextStyle(fontWeight: FontWeight.bold)),
          const SizedBox(height: 4),
          Text(content ?? 'Loading...'),
        ],
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Tag Details')),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(16.0),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            _section('UID', _uidResult),
            _section('Capability Container', _capabilityContainerResult),
            _section('NDEF', _ndefResult),
            _section('Memory Dump', _memoryDumpResult),
            _section('Chip Version', _chipVersionResult),
          ],
        ),
      ),
    );
  }
}
```
